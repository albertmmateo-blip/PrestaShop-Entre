# 🎓 PrestaShop Noob Guide

Welcome to the **Noob Guide** for PrestaShop! This folder contains beginner-friendly documentation to help you get started with PrestaShop development using Docker.

## 📚 What's Inside

### [Installation Guide](INSTALLATION_GUIDE.md)
A comprehensive, step-by-step guide for installing PrestaShop via Docker for local development.

**Perfect for**:
- Complete beginners to PrestaShop
- Developers new to Docker
- Anyone setting up a local development environment

**What you'll learn**:
- How to install Docker Desktop on Windows, macOS, or Linux
- How to install Git and clone the PrestaShop repository
- How to start and manage your PrestaShop development environment
- Common issues and how to fix them
- Next steps for learning PrestaShop development

## 🚀 Quick Start

If you're brand new and want to get started immediately:

1. **Start Here**: [INSTALLATION_GUIDE.md](INSTALLATION_GUIDE.md)
2. Follow the guide step-by-step
3. Don't skip the prerequisites!
4. Take your time - first-time setup can take 30-45 minutes

## 💡 Why Docker?

Docker makes it easy to:
- ✅ Set up PrestaShop without complex configuration
- ✅ Run the same environment on any computer
- ✅ Avoid conflicts with other software
- ✅ Start fresh anytime with a clean installation
- ✅ Match the production environment closely
