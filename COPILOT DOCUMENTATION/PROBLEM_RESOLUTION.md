```smarty

       id="quantity_wanted"
       data-unity="{$product.unity}"  {* ← ADD THIS LINE *}
```

## Troubleshooting

### Problem: Nothing Changes
**Check:**
1. Did you run `npm run build`?
2. Did you clear PrestaShop cache?
3. Did you hard refresh browser (Ctrl+Shift+R)?

### Problem: Still Shows Integers
**Check:**
1. Does product have `data-unity="m"` in HTML? (Inspect element)
2. Is product Unity field set to "m" in admin?
3. Any JavaScript errors in console? (F12 → Console tab)

### Problem: JavaScript Not Loading
**Check:**
1. Is `core.js` in Network tab?
2. Any 404 errors?
3. Did build complete successfully?

### Problem: All Products Converting
**Check:**
1. Remove `data-unity` from standard products
2. Use conditional: `{if $product.unity == 'm'}...{/if}`
3. Only set Unity to "m" for appropriate products
