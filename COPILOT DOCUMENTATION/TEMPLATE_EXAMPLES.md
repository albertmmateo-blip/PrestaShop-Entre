## Example 1: Add-to-Cart Form (Minimal Change)

### Location
Typically found in: `templates/catalog/_partials/product-add-to-cart.tpl` or similar

### Original Code (Before)
```smarty
<div class="product-add-to-cart">
  <form id="add-to-cart-or-refresh" action="{$urls.pages.cart}" method="post">
    <input type="number" 
           id="quantity_wanted" 
           name="qty" 
           value="{$product.minimal_quantity}" 
           class="input-group" 
           min="{$product.minimal_quantity}" />
    <button type="submit" class="btn btn-primary add-to-cart">
      Add to cart
    </button>
  </form>
</div>
```

### Modified Code (After) - Minimal Change
```smarty
<div class="product-add-to-cart">
  <form id="add-to-cart-or-refresh" 
        action="{$urls.pages.cart}" 
        method="post"
        data-unity="{$product.unity}">  {* ← ADD THIS LINE *}
    <input type="number" 
           id="quantity_wanted" 
           name="qty" 
           value="{$product.minimal_quantity}" 
           class="input-group" 
           min="{$product.minimal_quantity}" />
    <button type="submit" class="btn btn-primary add-to-cart">
      Add to cart
    </button>
  </form>
</div>
```

**What Changed:**
- Added `data-unity="{$product.unity}"` to the form tag
- That's it! The JavaScript will handle the rest

## Example 2: Quantity Input (Enhanced)

### Modified Code with Conditional Step

```smarty
<div class="product-quantity">
  <label for="quantity_wanted">Quantity</label>
  <input type="number" 
         id="quantity_wanted" 
         name="qty" 
         value="{$product.minimal_quantity}" 
         class="input-group"
         data-unity="{$product.unity}"
         {if $product.unity == 'm' || $product.unity == 'meter'}
           step="0.05"
           min="0.05"
         {else}
           step="1"
           min="{$product.minimal_quantity}"
         {/if} />
  
  {* Optional: Show unit label *}
  {if $product.unity}
    <span class="unit-label">{$product.unity}</span>
  {/if}
</div>
```

**Features:**
- Adds `data-unity` for meter detection
- Sets `step="0.05"` for meter products
- Sets `step="1"` for standard products
- Shows unit label (optional)

                     min="0.05"

                     step="1"
                     min="{$product.minimal_quantity}"

                   aria-label="{l s='Quantity' d='Shop.Theme.Actions'}" />

                    class="btn btn-touchspin js-touchspin"

          {if $product.unity}

              {if $product.unity == 'm'}
                {l s='Sold by meter' d='Shop.Theme.Catalog'}
              {else}
                {l s='Unit:' d='Shop.Theme.Catalog'} {$product.unity}
              {/if}
            </small>
          {/if}
        </div>
      </div>

      {* Add to Cart Button *}
      <div class="add">
        <button type="submit" 
                class="btn btn-primary add-to-cart" 
                data-button-action="add-to-cart"
                {if !$product.add_to_cart_url}disabled{/if}>
          <i class="material-icons shopping-cart">shopping_cart</i>
          {l s='Add to cart' d='Shop.Theme.Actions'}
        </button>

  {/if}

## Testing Your Changes

### After Modifying Templates

1. **Clear Cache:**
```bash
php bin/console cache:clear
```

2. **Hard Refresh Browser:**
- Press `Ctrl+Shift+R` (Windows/Linux)
- Press `Cmd+Shift+R` (Mac)

3. **Test Functionality:**
- View product page
- Check quantity input shows decimals (for meter products)
- Enter 2.71 → Should round to 2.75
- Add to cart and verify

## Common Smarty Variables

These are standard PrestaShop variables available in product templates:

| Variable | Description | Example |
|----------|-------------|---------|
| `{$product.unity}` | Unit of measurement | "m", "kg", "L" |
| `{$product.minimal_quantity}` | Minimum order quantity | 1, 0.05 |
| `{$product.id}` | Product ID | 42 |
| `{$product.id_product}` | Product ID (alias) | 42 |
| `{$product.quantity}` | Available stock | 100 |
| `{$product.add_to_cart_url}` | Cart URL | "/cart?add=1..." |
