# Quick Start Guide: Meter-Based Quantities

## TL;DR - Get It Working in 5 Minutes

### Step 1: Build JavaScript (2 minutes)

```bash
cd themes/
npm install  # First time only
npm run build
```

### Step 2: Set Product Unity (1 minute)

In PrestaShop admin:
1. Go to **Catalog > Products**
2. Edit a product
3. **Quantities** tab
4. Set **Unit for the price per unit** to: **m**
5. Save

### Step 3: Modify Template (2 minutes)

Find your product template quantity input and add `data-unity`:

```smarty
<input 
  type="number" 
  id="quantity_wanted"
  data-unity="{$product.unity}"
  {if $product.unity == 'm'}step="0.05"{/if}
/>
```

### Step 4: Clear Cache

```bash
php bin/console cache:clear
```

### Step 5: Test

1. Go to the product page
2. Quantity should show as `1.00` (decimal)
3. Enter `2.71` → Should round to `2.75`
4. Add to cart → Should work correctly

## Two Product Types

### Meter-Based Products (with `data-unity="m"`)
- Shows: `1.00`, `1.25`, `2.75` meters
- Rounds UP to nearest 0.05
- Stores as centimeters (100, 125, 275)

### Standard Products (without marker)
- Shows: `1`, `2`, `3` units
- No rounding
- Stores as entered
