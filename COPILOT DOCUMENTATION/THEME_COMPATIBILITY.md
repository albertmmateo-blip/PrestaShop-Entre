## Overview

The meter-based quantity system is **fully compatible with both Classic and Hummingbird themes** (and any other PrestaShop themes that follow standard conventions).

**PrestaShop Version**: Tested with PrestaShop 9.1+

## How It Works

### Shared Core JavaScript

The meter-based quantity functionality is implemented in the **shared core JavaScript** that all PrestaShop themes use:

```
themes/_core/js/quantity-meters.js  ← Core meter functionality
themes/_core/js/theme.js            ← Imports and initializes the module
```

These files are compiled by webpack into:
```
themes/core.js                      ← Used by ALL themes
```

### Theme-Independent Design

The implementation is deliberately theme-agnostic:

1. **Standard Selectors**: Uses PrestaShop's standard selector `#quantity_wanted`
   ```javascript
   prestashop.selectors.quantityWanted  // Defined in selectors.js
   ```

2. **Standard Events**: Listens to PrestaShop's standard events
   ```javascript
   prestashop.on('updatedProduct', ...)
   ```

3. **Standard Form Elements**: Works with standard HTML form elements
   ```html
   <input id="quantity_wanted" name="qty" type="number" />
   ```

## How to Enable for Your Theme

The meter-based quantity system is **automatically available** for any theme that includes PrestaShop's core JavaScript. No theme-specific configuration is needed.

### For Product Developers

To enable meter-based quantities for a specific product, add one of these markers to your product template:

#### Option 1: Data Attribute on Input
```html
<input type="number" 
       id="quantity_wanted" 
       name="qty"
       data-unity="m"
       value="1" />
```

#### Option 2: Data Attribute on Form
```html
<form data-unity="m">
  <input type="number" id="quantity_wanted" name="qty" value="1" />
</form>
```

#### Option 3: CSS Class on Input
```html
<input type="number" 
       id="quantity_wanted" 
       name="qty"
       class="quantity-meters"
       value="1" />
```

#### Option 4: CSS Class on Form
```html
<form class="product-meters">
  <input type="number" id="quantity_wanted" name="qty" value="1" />
</form>
```

#### Option 5: Data Attribute on Page
```html
<div data-product-unity="m">
  <!-- Product details -->
</div>
```

### For Theme Developers

If you're developing a custom theme:

1. **Include core.js**: Make sure your theme includes PrestaShop's compiled core.js
   ```html
   <script src="{$urls.base_url}themes/core.js"></script>
   ```

2. **Use standard selector**: Ensure quantity inputs use the ID `quantity_wanted`
   ```html
   <input id="quantity_wanted" name="qty" type="number" />
   ```

3. **Follow PrestaShop conventions**: Use standard PrestaShop form structures and CSS classes

## Potential Theme Issues

### If meter conversion doesn't work in your theme:

1. **Check core.js is loaded**
   - View page source
   - Look for `<script src="themes/core.js"></script>`

2. **Check quantity input ID**
   - Inspect the quantity input element
   - Verify it has `id="quantity_wanted"`

3. **Check for JavaScript errors**
   - Open browser console (F12)
   - Look for errors related to prestashop or jquery

4. **Check jQuery is loaded**
   - The module requires jQuery 3.x
   - Should be loaded before core.js

5. **Check meter markers are present**
   - Add `data-unity="m"` to test
   - Check browser console for "meter mode" messages
