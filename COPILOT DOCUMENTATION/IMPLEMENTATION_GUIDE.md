# Implementation Guide: Meter-Based Quantity System

## Overview

This guide provides complete step-by-step instructions to implement the meter-based quantity system in your PrestaShop 9.1 installation. The system allows products to be sold by meter with decimal quantities (like 1.25m, 2.75m) while storing values as integers (centimeters) internally.

## Step 1: Build the JavaScript

The meter-based quantity functionality is written in JavaScript located in `themes/_core/js/quantity-meters.js`. You need to compile it using webpack.

### 1.1 Navigate to Themes Directory

```bash
cd /path/to/your/prestashop/themes/
```

### 1.2 Install Dependencies (First Time Only)

```bash
npm install
```

This will install all required dependencies including webpack, jQuery, and build tools.

### 1.3 Build the JavaScript

```bash
npm run build
```

**Expected Output:**
```
webpack 5.94.0 compiled successfully in 2000 ms
✅ core.js: 143 KB
```

### 1.4 Verify Build Output

The build process should create `core.js` which includes the meter-quantity functionality. This file is used by all PrestaShop themes.

## Step 3: Enable Meter Mode for Products

The JavaScript functionality is **conditional** - it only activates when products are explicitly marked. There are two main methods:

### Method A: Template Modification (Recommended)

This method automatically enables meter mode for products with Unity field set to "m".

#### 3.1 Locate Product Template

Find your theme's product template. Common locations:
- Classic theme: Look in test or vendor directories for reference
- Custom theme: `themes/your_theme/templates/catalog/product.tpl`

#### 3.2 Find the Quantity Input

Look for the quantity input field, typically:

```smarty
<input 
  type="number" 
  id="quantity_wanted" 
  name="qty" 
  value="{$product.minimal_quantity}"
  class="input-group" 
/>
```

#### 3.3 Add the Data Attribute

Modify the input to include the `data-unity` attribute:

```smarty
<input 
  type="number" 
  id="quantity_wanted" 
  name="qty" 
  value="{$product.minimal_quantity}"
  class="input-group"
  data-unity="{$product.unity}"
  {if $product.unity == 'm' || $product.unity == 'meter'}
    step="0.05"
    min="0.05"
  {/if}
/>
```

**Key Changes:**
- Added `data-unity="{$product.unity}"` - Passes unity from product
- Added conditional `step="0.05"` for meter products
- Added conditional `min="0.05"` to prevent zero quantities

#### 3.4 Alternative: Add to Form

You can also add the attribute to the form element:

```smarty
<form 
  id="add-to-cart-or-refresh" 
  action="{$urls.pages.cart}" 
  method="post"
  data-unity="{$product.unity}"
>
  <!-- form contents -->
  <input type="number" id="quantity_wanted" name="qty" value="1" />
</form>
```

### Method B: Per-Product Configuration

For individual products, set the Unity field in the admin panel:

#### 3.5 Configure Product Unity

1. Go to **Catalog > Products**
2. Edit the product you want to sell by meter
3. Go to **Quantities** tab
4. Find **Unit for the price per unit** field
5. Enter: **m** (for meters)
6. Save the product

The template modifications in Method A will automatically detect this and enable meter mode.

### Method C: CSS Class Markers

For more control, add CSS classes directly:

```smarty
{* For meter-based products *}
<input 
  type="number" 
  id="quantity_wanted" 
  class="quantity-meters"
  value="1"
  step="0.05"
/>

{* Or on the form *}
<form class="product-meters">
  <input type="number" id="quantity_wanted" value="1" />
</form>
```

## Step 4: Testing

### 4.1 Test Meter-Based Products

For products marked with `data-unity="m"`:

1. **Display Test:**
   - Quantity should show as decimal: `1.00`
   - Input step should be `0.05`

2. **Rounding Test:**
   - Enter: `2.71` → Should round to: `2.75`
   - Enter: `2.76` → Should round to: `2.80`
   - Enter: `1.23` → Should round to: `1.25`

3. **Add to Cart Test:**
   - Add `2.75` meters to cart
   - Cart should show correct quantity
   - Backend should store `275` (centimeters)

### 4.2 Test Standard Products

For products WITHOUT meter markers:

1. **Display Test:**
   - Quantity should show as integer: `1`, `2`, `3`
   - Input step should be `1`

2. **No Conversion Test:**
   - Enter: `3` → Should stay: `3`
   - No rounding should occur

3. **Add to Cart Test:**
   - Add `3` units to cart
   - Cart should show `3`
   - Backend should store `3`

### 4.3 Testing Checklist

- [ ] JavaScript builds without errors

- [ ] Meter-based products show decimal quantities
- [ ] Rounding works correctly (2.71 → 2.75)
- [ ] Standard products remain unchanged

- [ ] Add to cart works for standard products
- [ ] Cart displays correct quantities

## Troubleshooting

### Problem: JavaScript Not Loading

**Symptoms:** Quantities still show as integers, no rounding occurs

**Solutions:**
1. Check if npm build completed successfully
2. Clear PrestaShop cache
3. Hard refresh browser (Ctrl+Shift+R)
4. Check browser console for errors
5. Verify core.js is included in page source

### Problem: Meter Mode Not Activating

**Symptoms:** JavaScript loads but products don't convert to meters

**Solutions:**
1. Verify product has `data-unity="m"` attribute
2. Check product Unity field in admin (should be "m")
3. Inspect element in browser to see actual HTML
4. Check browser console for `shouldEnableMeterMode` debug messages

### Problem: All Products Converting to Meters

**Symptoms:** Standard products incorrectly showing decimal quantities

**Solutions:**
1. Remove `data-unity="m"` from products that shouldn't use meters
2. Use conditional logic in templates (see Method A step 3.3)
3. Only set Unity field to "m" for appropriate products

### Problem: Rounding Not Working

**Symptoms:** Can enter any decimal, not rounding to 0.05 multiples

**Solutions:**
1. Check browser console for JavaScript errors
2. Verify jQuery is loaded (required dependency)
3. Ensure prestashop global object exists
4. Check if other JavaScript conflicts exist

### Problem: Add to Cart Fails

**Symptoms:** Adding products to cart doesn't work

**Solutions:**
1. Check browser console for errors
2. Verify AJAX requests are sent correctly
3. Check if quantity is being converted to centimeters
4. Ensure PrestaShop cart handling wasn't modified elsewhere

## Advanced Configuration

### Custom Rounding Intervals

To change the rounding interval from 0.05 (default) to something else, modify `quantity-meters.js`:

```javascript
// Change this constant at the top of the file
const METER_STEP = 0.05;  // Change to 0.10, 0.25, etc.
```

Then rebuild: `npm run build`

### Custom Unit Labels

To display "meters" next to quantities, modify your template:

```smarty
<div class="input-group">
  <input type="number" id="quantity_wanted" data-unity="{$product.unity}" />
  {if $product.unity == 'm'}
    <span class="input-group-text">meters</span>
  {/if}
</div>
```

### Multiple Units Support

The system currently supports meters. To add feet, yards, etc.:

1. Modify `shouldEnableMeterMode()` in `quantity-meters.js`
2. Add checks for additional units
3. Create separate conversion functions if needed
