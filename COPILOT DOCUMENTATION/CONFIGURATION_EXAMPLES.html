📏 Meter-Based Product Configuration Guide

⚠️ Important: The meter-based quantity system is conditional. Only products marked with specific indicators will use meter conversion. All other products use standard PrestaShop integer quantities.

Option 1: Data Attribute on Quantity Input

METER-BASED

Best for: Direct control on the quantity input element

<form action="/cart" method="post">
    <input type="number" 
           id="quantity_wanted" 
           name="qty"
           data-unity="m"
           value="1" />
    <button type="submit">Add to Cart</button>
</form>

Option 2: Data Attribute on Product Form

METER-BASED

Best for: Applying to entire form/product

<form action="/cart" method="post" data-unity="m">
    <input type="number" 
           id="quantity_wanted" 
           name="qty"
           value="1" />
    <button type="submit">Add to Cart</button>
</form>

Option 3: CSS Class on Quantity Input

METER-BASED

Best for: Styling and functionality together

<form action="/cart" method="post">
    <input type="number" 
           id="quantity_wanted" 
           name="qty"
           class="quantity-meters"
           value="1" />
    <button type="submit">Add to Cart</button>
</form>

Option 4: CSS Class on Product Form

METER-BASED

Best for: Theme-based identification

<form action="/cart" method="post" class="product-meters">
    <input type="number" 
           id="quantity_wanted" 
           name="qty"
           value="1" />
    <button type="submit">Add to Cart</button>
</form>

Option 5: Data Attribute Anywhere on Page

METER-BASED

Best for: Flexible placement, works from any container

<div class="product-details" data-product-unity="m">
    <h1>Fabric Roll - Sold by Meter</h1>
    <form action="/cart" method="post">
        <input type="number" 
               id="quantity_wanted" 
               name="qty"
               value="1" />
        <button type="submit">Add to Cart</button>
    </form>
</div>

Standard Product (No Meter Conversion)

STANDARD

Default behavior: Regular integer quantities without conversion

<form action="/cart" method="post">
    <input type="number" 
           id="quantity_wanted" 
           name="qty"
           value="1" />
    <button type="submit">Add to Cart</button>
</form>

This product will use standard PrestaShop integer quantities (1, 2, 3, etc.)

Using PrestaShop's Unity Field

METER-BASED

Recommended approach: Use PrestaShop's built-in unity field

In your PrestaShop product configuration:

  • Navigate to product edit page
  • Find the "Unity" field
  • Set it to "m" or "meter"
  • In your theme template, add: data-unity="{$product.unity}"
<!-- In your product template (e.g., product.tpl) -->
<form action="{$urls.pages.cart}" method="post" data-unity="{$product.unity}">
    <input type="number" 
           id="quantity_wanted" 
           name="qty"
           value="{$product.minimal_quantity}" />
    <button type="submit">{l s='Add to cart'}</button>
</form>

Testing Your Configuration

Quick Test:
  1. Add one of the meter indicators to your product
  2. Open the product page in a browser
  3. Open browser DevTools Console
  4. Check if the quantity input shows decimal values (e.g., "1.00")
  5. Try entering "2.71" - it should change to "2.75"
  6. If it works, your product is meter-based ✅
  7. If not, check that JavaScript is loaded and indicators are correct
