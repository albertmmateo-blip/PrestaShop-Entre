## 🚀 How to Use

### For Development
```bash
cd /path/to/PrestaShop-Entre/themes/entretelas

# Build once
npm run build

# Watch mode (auto-rebuild)
npm run watch

# Development server
npm run dev
```

### For Deployment
1. Clone repository
2. Navigate to `themes/entretelas`
3. Run `npm install`
4. Run `npm run build`
5. Activate in PrestaShop
